**Beets** is an AI-powered PowerPoint add-in that brings Cursor-like natural language editing to presentation creation.

Users can chat with AI to generate, modify, and enhance slides while reviewing changes component-by-component before applying them.

The system is built as a multi-service architecture consisting of a React-based PowerPoint add-in, a Go orchestrator service, a Python FastAPI service for slide operations, and a TypeScript MCP server providing AI tools and file integrations.

Features include natural language slide generation, component-wise change tracking, cross-file references (Excel/PPT), theme management, and automated layout alignment.

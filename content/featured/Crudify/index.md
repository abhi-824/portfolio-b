A command-line tool available as an NPM package which creates a starter backend project consisting of CRUD API endpoints and a configured PostgreSQL database (using Prisma ORM) from just an ER Diagram which the user needs to provide in JSON format. Available on [npm](https://www.npmjs.com/package/crudify-dtu).
